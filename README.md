# Attendance Management System with Telegram Notifications

## 1. Project Overview
The Attendance Management System is a C-based application designed to record student attendance and send instant notifications through Telegram.

It provides a simple way to update attendance status and communicate the attendance information using a Telegram bot.

## 2. Objectives
- To simplify the process of recording student attendance.
- To maintain student attendance information.
- To automate attendance notifications using Telegram.
- To understand the practical implementation of C programming and API integration.

## 3. Technologies Used
- **Programming Language:** C
- **API:** Telegram Bot API
- **Notification:** Telegram Bot
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 4. Features
- Accepts student name and SAP ID.
- Allows attendance status selection.
- Generates an attendance update.
- Sends notifications through Telegram.

## 5. Working
1. The program starts and accepts student information.
2. The user selects the attendance status.
3. The program generates an attendance message.
4. The Telegram Bot API is used to send the notification.
5. A notification status is displayed.
